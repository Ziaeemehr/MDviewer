# MD Viewer

نمایشگر ساده و سبک Markdown برای متن‌های فارسی و انگلیسیِ درهم، با پشتیبانی از فرمول‌های LaTeX.

## نحوه‌ی استفاده

1. مخزن را دانلود یا clone کنید.
2. فایل `index.html` را در مرورگر باز کنید.

نصب، سرور و اینترنت لازم نیست. فقط پوشه‌ی `vendor/` باید کنار `index.html` بماند.

متن را در ویرایشگر سمت چپ بنویسید یا جای‌گذاری کنید، یا یک فایل `.md` را با دکمه‌ی «باز کردن» یا کشیدن به داخل صفحه باز کنید. پیش‌نمایش هم‌زمان به‌روز می‌شود.

## قابلیت‌ها

- **متن دوجهته:** هر پاراگراف، تیتر، مورد فهرست و خانه‌ی جدول جهتش را از اولین حرف خودش می‌گیرد. با دکمه‌ی جهت می‌توان همه را راست‌به‌چپ یا چپ‌به‌راست کرد.
- **فرمول:** با KaTeX، به شکل‌های `$...$`، `$$...$$`، `\(...\)` و `\[...\]`.
- **تم تاریک و روشن**
- **Markdown به سبک GitHub:** جدول، فهرست کار و بلوک کد با دکمه‌ی کپی.
- **خروجی:** ذخیره به صورت `.md` و PDF از طریق چاپ مرورگر.
- **ویرایشگر:** قابل پنهان کردن، با جداکننده‌ی قابل کشیدن و اسکرول هم‌گام با پیش‌نمایش.
- **خصوصی:** همه‌چیز در مرورگر شما می‌ماند. متن، تم و چیدمان در حافظه‌ی مرورگر ذخیره می‌شود.
